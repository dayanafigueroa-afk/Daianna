## Qué se hizo

1. ✅ Inicializado proyecto **Next.js 16** con React 19
2. ✅ Instaladas dependencias: `@supabase/supabase-js`, `lucide-react`
3. ✅ Copiado prototipo **NEXO.jsx** como componente base
4. ✅ Creada estructura de carpetas:
